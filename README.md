# Burpsuite
Burp Suite works as an intercepting proxy, allowing a security tester to capture, inspect, modify, and forward HTTP/HTTPS requests and responses between a browser and a web server.

Step 1 sudo apt install openjdk-21-jdk -y

Step 2 java -version

Step 3 sudo update-alternatives --config java = Chose here openjdk21

Step 4 wget -qO- https://raw.githubusercontent.com/xiv3r/Burpsuite-Professional/main/install.sh | sudo bash

Step 5 burpsuitepro = to start burp suite pro
